# Weather C+F

A macOS card that shows Fahrenheit and Celsius together, so you can get used to how the two scales relate. Current temperature, the next few hours, and the coming days all show both units at once. Pin it on the desktop, or add it as a widget.

**Download (recommended)** → [GitHub Releases (latest)](https://github.com/yxwvwxy/weather-c-f/releases/latest)

Requires macOS 14 or later. On first open, right-click the app and choose Open.
